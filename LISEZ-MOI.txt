COURSE AU TRAIT - site courseautrait.fr

Structure
- index.html : la page d'accueil du site (courseautrait.fr)
- jeu/       : le jeu (courseautrait.fr/jeu/), avec son manifeste et ses icônes

Mise à jour sur GitHub
1. Ouvre le dépôt, onglet Code, puis Add file > Upload files.
2. Décompresse ce dossier, puis glisse index.html et le dossier jeu dans la zone de dépôt.
   (GitHub garde l'arborescence : jeu/index.html, jeu/icons/...)
3. Commit changes. La mise à jour est en ligne au bout d'une minute.

Ensuite
- courseautrait.fr affiche la page d'accueil.
- Le bouton « Jouer maintenant » ouvre courseautrait.fr/jeu/.
- Sur téléphone, « Sur l'écran d'accueil » depuis la page du jeu installe l'icône qui ouvre directement le jeu.
